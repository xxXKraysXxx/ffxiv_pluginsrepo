# vfallgay

Русский форк [vfallguy](https://github.com/awgil/ffxiv_vfallguy) для Fall Guys в FFXIV. Авторы оригинала — veyn и участники проекта; изменения форка — krays.

Версия **0.0.0.11**, Dalamud API **15**, .NET **10**.

## Установка

Добавить в Custom Plugin Repositories в настройках Dalamud:

```text
https://raw.githubusercontent.com/xxXKraysXxx/ffxiv_pluginsrepo/refs/heads/main/plug_repos.json
```

Установить или обновить **vfallgay** через установщик плагинов. Внутреннее имя сохранено, поэтому уже установленный vfallgay получит обновление.

## Возможности

- Автоматическая регистрация с настраиваемой задержкой.
- Авто выход при превышении выбранного количества игроков.
- Авто выход при поражении, когда появляется `_FGSEliminated`.
- Кнопки регистрации и быстрого выхода.
- Подсветка зон и предложенного пути на третьем этапе.
- Русский интерфейс.

Окно появляется в зоне события. Автоматизация включается соответствующими галочками; настройки, как и раньше, действуют до перезагрузки плагина.

## Основа обновления

Последний проверенный upstream: `7715d9a1fa13754927cb95d785297f1d7bb584b5` от 2026-04-29, ветка `master`, проверено 2026-10-08.

Перенесены изменения API 15: новый доступ к LocalPlayer, ObjectKind.Pc и обработчик ActionEffectHandler. Сохранены авто выход при поражении, русский перевод, имя и оформление форка. Дополнительно:

- Авто выход проверяет зону события, состояние дюти и переход между зонами; ожидающий выход не добавляется повторно каждый кадр.

- При выгрузке отписывается обработчик отрисовки окна.
- Переведены оставшиеся кнопки и подписи.

## Сборка и проверки

Требуются .NET SDK 10 и локальные библиотеки Dalamud API 15. На Windows SDK использует `%APPDATA%\XIVLauncher\addon\Hooks\dev`.

```powershell
dotnet build vfallgay.sln -c Release -p:RestoreLockedMode=true
dotnet run --project tests/Checks.csproj -c Release
```

Установочный архив: `vfallgay/bin/x64/Release/vfallgay/latest.zip`.

Сборка Release проверена с Dalamud 15.0.3.6: без ошибок и предупреждений. 13 поведенческих проверок выполняют настоящий код MainWindow/GameEvents с подменёнными игровыми сервисами. Проверяются условия авто выхода, отсутствие дубликатов при 300 кадрах и передача ID действий для AOE. Проверка внутри FFXIV не проводилась; нативные сигнатуры и взаимодействие с игровым UI требуют проверки в игре.
